# Go-live checklist

## Before first deployment

1. [ ] Run `scripts\windows-prepare-deploy.cmd` from the project root.
2. [ ] Confirm all automated tests pass; commit the generated `package-lock.json`.
3. [ ] Push the project to a private GitHub repository.
4. [ ] Create the Neon Free PostgreSQL project. Copy the pooled app URL and direct backup URL.
5. [ ] Create Dbrij Storage Free account (advertised no-card signup).
6. [ ] Create two Dbrij buckets: `portfolio-media` (**public**) and `portfolio-backups` (**private**).
7. [ ] Create two Dbrij S3 keys (media key and backup key). On Free, keys are storage-space-wide, not bucket-scoped; this is a known limitation.
8. [ ] Set Render environment variables: `DATABASE_URL`, `OWNER_EMAIL`, `WHATSAPP_NUMBER`, `DBRIJ_S3_ENDPOINT`, `DBRIJ_S3_REGION`, `DBRIJ_BUCKET`, `DBRIJ_KEY_ID`, `DBRIJ_KEY_SECRET`, `DBRIJ_MEDIA_PUBLIC_BASE` (HTTPS), and optional Turnstile keys. `AUTH_SECRET` is generated by the Blueprint.
9. [ ] Set GitHub Actions secrets: `NEON_BACKUP_DATABASE_URL`, `DBRIJ_BACKUP_BUCKET`, `DBRIJ_BACKUP_KEY_ID`, `DBRIJ_BACKUP_KEY_SECRET`, `BACKUP_ENCRYPTION_PASSPHRASE`, `RENDER_DEPLOY_HOOK`.
10. [ ] Run `npm run deploy:check` then `npm run verify:production` from a machine with production `.env` values set privately.
11. [ ] Run one manual GitHub backup and verify `.dump.enc`, `.sha256` and `.hmac` objects appear in the private bucket.
12. [ ] Restore one encrypted backup into a separate test database and verify the data.
13. [ ] Test contact form, Turnstile if enabled, WhatsApp handoff, all CMS edit flows and public media links.
14. [ ] Test mobile/tablet/desktop browser layouts.

## Before accepting real customer enquiries

15. [ ] Configure a real email provider/sender if customer notifications are needed. `EMAIL_PROVIDER=log` does not send email.
16. [ ] Confirm Dbrij storage and transfer allowance in the dashboard. Current Dbrij docs differ: product page lists 25 GB monthly served, detailed docs list 10 GB; use the lower figure for planning.
17. [ ] Review free-tier limits and understand that Render Free is not an always-on production SLA.
18. [ ] Keep the `.com.ng` purchase deferred; register it later when budget permits and then update `SITE_URL`, DNS and Turnstile hostname.

## Credentials and card status

- Dbrij Storage Free, Neon Free, Render Free, GitHub Free and Brevo Free are the selected no-card tiers according to their published free-plan information.
- Cloudflare R2 was removed because activation prompted for a payment method. Optional Cloudflare Turnstile is separate from R2 and does not require R2 activation.
- Cloudinary is not used in this chosen setup; its Free plan also advertises no card, but it is unnecessary when Dbrij handles media and backups.
- OpenAI API and paid WhatsApp Business messaging are not configured. They may require billing/payment details if activated later.
- The `.com.ng` domain is a future paid purchase.
